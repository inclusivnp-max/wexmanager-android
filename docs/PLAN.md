# WexManager — план разработки

Файловый менеджер уровня MT Manager на Jetpack Compose + Material 3 Expressive.
Тестирование: эмулятор `mtvm` (Android 15, x86_64).

## Стек
- Kotlin 2.4, AGP 9 (built-in Kotlin), Compose BOM 2026.09, **Material3 1.5.0-alpha (Expressive API)**
- Navigation 3 (predictive back, анимированные переходы), Lifecycle ViewModel
- DataStore (типизированные настройки и пользовательские данные через kotlinx.serialization)
- Coil 3 (миниатюры изображений, видео, иконки APK, обложки), Telephoto (зум изображений)
- Sora Editor + лексеры/подсказки WEXdesktop (76 языков), ripgrep (Rust) для поиска, Media3 (аудио/видео)
- Apache Commons Compress + XZ (zip/7z/tar/gz/bz2/xz), MaterialKolor (палитры от seed-цвета)
- JSch / commons-net / smbj — сетевые хранилища (SFTP/FTP/FTPS/SMB)
- LeakCanary в debug-сборке, R8 в release (APK ~10 МБ вместо 87 МБ)
