# WexManager

Двухпанельный файловый менеджер для Android в духе MT Manager — на Jetpack Compose и Material 3 Expressive.

## Возможности

**Браузер**
- Две панели: свайп между ними в портрете, бок о бок в ландшафте и на планшетах (или одна панель — по настройке).
- Копирование/перемещение в соседнюю панель одним касанием, синхронизация панелей, обмен панелей местами.
- Выделение: касание иконки, протягивание как в MT (вправо от иконки, затем вверх/вниз с автопрокруткой), «всё», «инверсия», «такие же типы».
- Фильтр: текст, шаблоны `*.apk`, регулярные выражения `/regex`, отрицание `!текст`.
- История назад/вперёд, переход к пути с подсказками, закладки, недавние файлы, хлебные крошки (тома и архивы).
- Список и сетка (полноразмерные превью), миниатюры изображений/видео, обложки аудио, иконки APK.
- Предиктивный жест «назад» с анимацией, автообновление по FileObserver, быстрая прокрутка.
- Горячие клавиши: Ctrl+A/C/X/V, Del, F2, F5 / Ctrl+R, Tab, Backspace, Alt+←/→/↑, Ctrl+F, Ctrl+L, Ctrl+H (скрытые), Ctrl+N / Ctrl+Shift+N (файл / папка); в редакторе — Ctrl+S, Ctrl+F, Ctrl+G, Ctrl+O (структура), Ctrl+Shift+F (инструменты текста).

**Операции**
- Фоновые задачи с прогрессом, скоростью и ETA, уведомление, отмена; конфликты: заменить / пропустить / оставить оба / объединить (раздельно для файлов и папок).
- Корзина (`.WexTrash` в корне тома) с восстановлением и кнопкой «Отменить» сразу после удаления.
- Переименование, пакетное переименование (`{name}`, `{ext}`, `{n:3}`, `{date}`, `{parent}`, поиск/замена, regex, предпросмотр и проверка коллизий).
- Свойства: рекурсивный размер, права (chmod), владелец, MD5/SHA-1/SHA-256/CRC32; размеры всех папок по запросу.
- Архивы: ZIP/7z/RAR (RAR4 и **RAR5** — solid, многотомные, пароль, зашифрованные заголовки; распаковка во временную папку — неверный пароль или битые данные не затирают существующие файлы)/TAR/TAR.GZ/TAR.XZ/TAR.BZ2/GZ/XZ/BZ2 как папки, распаковка (в том числе пакетная — каждый в свою папку), **проверка целостности**, создание, **добавление и удаление файлов в ZIP**, редактирование файлов прямо внутри ZIP/APK.
- ZIP из Windows с именами в OEM-кодировке (CP866 для русского, GBK, Shift_JIS…) без флага UTF-8 распознаётся сам — имена не превращаются в «кракозябры».
- Пароли архивов: распаковка зашифрованных ZIP (AES/ZipCrypto), 7z и RAR, создание ZIP с AES-256, «частые пароли».
- **DEX-редактор** (как Dex Editor в MT, на clazzpatcher): пакеты и классы APK/DEX, правка класса в smali с проверкой сборки, новые и удалённые классы, поиск по классам и коду и замена во всех классах; при сохранении пересобираются только изменённые классы, остальные остаются байт в байт. **Java-код класса** — декомпиляция jadx, в том числе с несохранёнными правками.
- **Ресурсы и перевод** (`resources.arsc`): типы и конфигурации, правка значений (строки, цвета, размеры, ссылки), массивы и стили, режим перевода на новый язык с фильтром «только непереведённые».
- Правка JVM `.class` (отдельно и прямо в jar/apk): класс открывается текстом csmali, при сохранении собирается обратно.
- **Установка split-APK** (`.apks`, `.xapk`, `.apkm`) одной сессией PackageInstaller: части под ABI, плотность экрана и языки устройства отмечаются сами, OBB из xapk копируются в `Android/obb`.
- **Клон APK**: другое имя пакета, чтобы поставить копию рядом с оригиналом (компоненты остаются прежними классами, authorities провайдеров и собственные разрешения переименовываются).
- **Объединение split-APK в один APK**: таблицы ресурсов частей вливаются в основную (строки — вместе с оформлением), `lib/` и прочие файлы копируются с выравниванием, из манифеста убираются признаки обязательных частей, результат подписывается.
- Сохранение в APK по правилам zipalign: `resources.arsc` и несжатые записи выровнены по 4 байта, `.so` — по 16 КБ.
- APK: подробная информация, разрешения, подписи v1–v4, компоненты, ABI, DEX, **правка `AndroidManifest.xml` и других бинарных XML прямо в APK** (расшифровка, редактор, обратная сборка AXML с сохранением типов), **подпись APK** (v1+v2+v3) встроенным ключом или своим (PKCS12/BKS, pk8 + x509.pem — ключ хранится в Android Keystore).
- Ярлыки папок на рабочий стол, «открыть как» (с запоминанием для расширения), открытие файлов из других приложений (с записью изменений обратно в `content://`).
- Root-доступ (по желанию, только чтение): просмотр `/data` и системных разделов и открытие файлов оттуда копией (Magisk/KernelSU).
- `Android/data` и `Android/obb` без root: системный выбор папки, после него каталоги чужих приложений можно смотреть, копировать, переименовывать и удалять. Открытие файла из такой папки — копия только для просмотра.
- Цветные метки отдельных папок, домашняя папка для каждой панели, ярлыки «Загрузок» и закладок на иконке приложения.

**Просмотрщики и редактор**
- Редактор кода (Sora Editor + лексеры и подсказки из WEXdesktop): 76 языков (включая Smali с полной таблицей опкодов Dalvik из clazzpatcher, байт-код JVM, XML/манифест, Gradle, CSV с радужными колонками), инкрементальная подсветка — правка перелексирует только затронутые строки; автоподсказки как в десктопе: нечёткий поиск (префикс, CamelHumps, подстрока), слова и функции файла, шаблоны с полями, контекст для smali (опкоды, регистры, метки, типы), XML/Android (теги, атрибуты, значения, ресурсы), CSS, shell и путей, Ctrl+Space — вручную; темы — в том числе Material You, подстроенная под палитру приложения (цвета токенов берутся из выбранной темы по скоупам); поиск/замена/regex, переход к строке, отслеживание правок файла другими приложениями, кодировки, окончания строк, панель символов, мини-карта, sticky scroll, автосохранение, «Сохранить как», «Показать изменения» (diff с файлом на диске), быстрый переход между недавними файлами, инструменты текста (регистр, сортировка и уникальные строки, форматирование/сжатие JSON, форматирование XML, Base64, URL, `\uXXXX`, проверка синтаксиса JSON/XML с переходом к ошибке).
- Изображения (зум, листание по папке, EXIF), аудио/видео (Media3).
- PDF: встроенный просмотр (страницы по требованию, масштаб щипком/двойным тапом, переход к странице), миниатюры первой страницы в списке.
- ELF (`.so`, исполняемые): архитектура, SONAME, зависимости, JNI-функции, символы, сегменты и секции; проверка совместимости со страницами 16 КБ (Android 15+) — и для всех библиотек в сведениях об APK.
- Базы SQLite: таблицы и представления, постраничный просмотр, схема, SQL-запросы; правка ячеек и удаление строк — в явном режиме правки.
- Предпросмотр Markdown (GFM: таблицы, задачи, зачёркивание, автоссылки; HTML в тексте экранируется), HTML (JavaScript — по переключателю) и CSV/TSV таблицей — из меню редактора с несохранёнными правками.
- Шрифты TTF/OTF/TTC: название и версия из файла, образец текста любого размера, сетка символов с честным покрытием (кириллица/латиница/цифры по таблице cmap).
- HEX-редактор больших файлов: страничное чтение, правка байтов, undo/redo, запись чисел и строк, заполнение диапазона, резервная копия.

**Инструменты**
- Поиск по имени/шаблону/regex/содержимому с фильтрами; содержимое ищет встроенный ripgrep (Rust, как в WEXdesktop: в 8–20 раз быстрее обхода на Kotlin), без него или для выражений, которые понимает только Java, — встроенный поиск; анализатор хранилища, «Очистка памяти» (временные файлы, кеш миниатюр, лишние APK), менеджер приложений (извлечение APK/APKS), терминал.
- Сетевые хранилища SFTP/FTP/FTPS/SMB (с поиском общих папок на сервере) и WebDAV (Nextcloud, ownCloud, Яндекс.Диск; можно вставить полный URL): пароли в Android Keystore, проверка ключей хостов, загрузка/скачивание с очередью, правка удалённых файлов с отправкой обратно.
- Поиск дубликатов (размер → частичный хеш → SHA-1), сравнение файлов (diff Майерса, «рядом»/«единый»), сравнение и синхронизация папок двух панелей.
- Справочник инструкций Smali/Dalvik.

**Кастомизация**
- Тема (авто/светлая/тёмная, AMOLED), Material You или свой акцент, 9 стилей палитры, контраст, скорость анимаций.
- Иконки: 4 стиля, 6 форм Material Shapes, своя иконка для любого расширения (глиф + цвет или картинка), иконпаки (zip, загрузка по ссылке, шаблон для создания) и каталог готовых паков для загрузки в одно касание (Material Icon Theme, Catppuccin — MIT).
- Резервная копия настроек в JSON, поиск по настройкам.

## Go IDE: Material 3 Expressive

Элементы пространства Go используют нативные компоненты Compose Material 3 Expressive, а не отдельную рисованную тему:

- Акцентная morphing-кнопка Run / Stop в тулбаре; split button запуска и настроек в консоли; связанная группа `ToggleButton` для «Файл / Пакет».
- Сегментированные интерактивные `ListItem` для проектов, дерева, выбора папки, быстрого открытия и ошибок: формы нажатия / выбора задаёт библиотека. Состояния видны не только по цвету.
- Тональные округлые поля, заполненные кнопки подтверждения, контрастные icon buttons с морфингом и подсказками. Символы редактора — нативные 48 dp-кнопки вместо маленьких рисованных ячеек.
- Цвета берутся из текущей Material You-палитры WexTheme, включая тёмную тему; движение — из её Expressive MotionScheme и настройки скорости анимаций.
- Домашняя страница целиком прокручивается под шапкой, действия переносятся в столбец на узком экране / при крупном шрифте, формы создания прокручиваются. Контент проектов ограничен 720 dp, а широкое IDE-пространство сохраняет боковое дерево.

## Go IDE: компактный режим и проверка при наборе

- В открытом проекте убраны отдельная шапка проекта, нижняя навигация и дополнительный Run-тулбар. Вверху остаются файл / путь, Run, состояние синтаксиса, Save и меню; Undo / Redo находятся в панели символов. Меню дерева возвращает к списку проектов. Статус-бар и клавиатурные отступы больше не накладываются дважды; индикатор фоновой операции не меняет высоту редактора.
- Нажатие имени файла или **Ctrl+P** открывает поиск по всем папкам проекта, включая свёрнутые. В дереве есть поиск по пути, очистка запроса, «показать текущий файл», сворачивание всех папок. Раскрытые папки и видимость боковой панели сохраняются для каждого проекта.
- Диалоги создания проекта / файла / папки и открытия проекта остаются открыты при ошибке, сохраняют введённые данные, показывают причину и блокируют повторное подтверждение во время операции. Go-модуль подставляется из имени проекта и редактируется отдельно. Ошибки фоновых операций показываются уведомлением, не выталкивая код вверх.
- Консоль получила компактные действия вместо длинной ленты кнопок, отдельное окно настройки окружения и историю последних 40 команд. Черновик ввода сохраняется при сворачивании консоли. Ручная прокрутка отключает автоматическое следование за выводом; вернуть его можно через меню.

### Синтаксис Go прямо во время редактирования

Проверка включена по умолчанию и запускается через **450 мс после последнего изменения**. Вход — текущий несохранённый буфер редактора. Файл не записывается, программа не запускается, сеть и Termux не используются.

В APK включён небольшой JSON-сервис на стандартном [go/parser](https://pkg.go.dev/go/parser). Ошибки подчёркиваются в Sora; значок в тулбаре показывает состояние и количество ошибок. Нажатие открывает список с переходом к строке / столбцу; **F8 / Shift+F8** переключают ошибки. В этом же списке можно выключить автопроверку.

Проверка поддерживает Go-файлы до 1 MiB, показывает до 100 сообщений, корректно переводит UTF-8 позиции в UTF-16 редактора, включая кириллицу и emoji. Ответы предыдущих правок / вкладок отбрасываются; старая подсветка сразу убирается при следующем изменении. Есть отмена, таймаут и завершение процесса при уходе из редактора. Это синтаксический разбор: типы, наличие импортируемых пакетов и ошибки линковки проверяются при сборке.

Пересборка встроенного парсера: `tools/build-go-syntax.sh` (Go + NDK r28). Получаются `libgosyntax.so` для arm64-v8a и x86_64, исполняемые из `nativeLibraryDir`, с выравниванием ELF LOAD 16 КБ. Исходники и Go-тесты — `tools/go-syntax`; лицензия Go включена в assets. Настройка Termux нужна только для запуска пользовательских программ, не для подсветки ошибок.

## GO: отдельное IDE-пространство

Кнопка **GO** в главной нижней панели открывает отдельное рабочее пространство. Его проекты и вкладки отделены от обычного редактора файлового менеджера.

- **Создать проект** создаёт папку в `WexManager/GoProjects`, `go.mod`, готовый `main.go` и `.gitignore`. Имя модуля задаётся в диалоге.
- **Открыть папку** подключает существующий проект из общего хранилища. Есть выбор папки, ввод пути, список недавних проектов и восстановление последнего проекта / файла.
- Дерево папок загружается по мере раскрытия, сортирует папки первыми, поддерживает фильтр и создание файлов / папок в выбранном каталоге. Новые `.go`-файлы получают имя пакета соседних исходников.
- На телефоне дерево находится в выдвижной шторке, на экранах от 840 dp — в сворачиваемой боковой панели. Редактор с вкладками остаётся внутри IDE. Переключение проектов сохраняет их открытые буферы в течение жизни процесса.
- Анимации используют Material Expressive MotionScheme: переход между проектами и стартовой страницей, раскрытие / сворачивание боковой панели, появление / удаление / перемещение строк дерева, поворот стрелок папок, подсветка выбора и переключение Run / Stop. Панель консоли открывается штатной анимированной нижней шторкой.
- «Убрать из недавних» удаляет только запись списка, не файлы проекта. Пути операций проверяются относительно канонического корня проекта, включая символьные ссылки.

## Go: запуск из редактора

В обычном редакторе для `.go` под вкладками появляется тулбар **Go** (в IDE действия перенесены наверх) с кнопкой **Run / Stop** и раскрытием панели запуска. **F5** запускает файл/пакет, **Shift+F5** останавливает процесс. Панель можно свернуть, продолжая редактирование.

- При наличии ближайшего `go.mod` по умолчанию собирается пакет вместе с соседними `.go`-файлами. Откройте `cmd/server/main.go`, чтобы запускать именно этот entry point. Для одиночных скриптов есть режим «Этот файл».
- В «Параметрах» сохраняются режим запуска, аргументы с кавычками, рабочая папка и переключатель синхронизации импортов — отдельно для каждого файла.
- Перед выполнением сохраняются изменённые открытые файлы проекта. Ошибка сохранения или новые правки во время подготовки отменяют запуск.
- **Подтянуть импорты** выполняет `go mod tidy`, **go get** добавляет `модуль@версия`, **Модуль** создаёт `go.mod`. Автосинхронизация перед Run / Test включена по умолчанию и обновляет `go.mod` / `go.sum`; её можно отключить. Это управление зависимостями, а не LSP-автодобавление строк `import` в исходник.
- Для `_test.go` основное действие — **Тесты** (`go test ./...`).
- Вывод компилятора и программы поступает в панель в реальном времени. Поле ввода отправляет строку в stdin, **EOF** закрывает ввод. **Консоль** открывает постоянную Bash-оболочку в выбранной рабочей папке: доступны `cd`, `go get`, `go test`, `go env` и обычные команды. Это построчная консоль, не PTY; полноэкранные TUI доступны в самом Termux.
- Stop завершает группу процессов, включая компилятор и запущенную программу. Закрытие редактора также отправляет остановку. Исполняемый файл и FIFO создаются во временной приватной папке Termux, а не на разделе общего хранилища с `noexec`.
- Панель показывает последние 250 КБ текста; полный журнал доступен через меню «Копировать путь журнала». Журнал ограничен 8 MiB, старые каталоги сессий удаляются после семи дней. После команд открытые файлы проверяются на изменения с диска.

### Однократная настройка окружения Go

Установите [Termux из официального репозитория](https://github.com/termux/termux-app/releases), запустите его и выполните:

```sh
pkg update && pkg install golang coreutils util-linux
termux-setup-storage
mkdir -p ~/.termux
touch ~/.termux/termux.properties
sed -i '/^[[:space:]]*allow-external-apps[[:space:]]*=/d' ~/.termux/termux.properties
printf '%s\n' 'allow-external-apps = true' >> ~/.termux/termux.properties
termux-reload-settings
```

В панели Go → **Окружение** эти команды можно скопировать, открыть Termux и выдать WexManager разрешение на запуск команд. Termux и WexManager нужен доступ к общему хранилищу. Проект храните, например, в `Download/Go`, не в приватных каталогах приложения / `Android/data`. Файлы из архивов и `content://` сначала сохраните или распакуйте вместе с проектом в общую папку.

Интеграция использует официальный [Termux RUN_COMMAND API](https://github.com/termux/termux-app/wiki/RUN_COMMAND-Intent): явный service intent и результат через явный PendingIntent, без экспортированного приёмника. Go SDK не включён в APK. Подготовка и файловый обмен выполняются на IO-диспетчере; stdout/stderr объединены, ввод отправляется через атомарные файлы очереди и приватный FIFO.

Тесты: `GoRunPlanTest` проверяет обнаружение модулей, аргументы/кавычки, реальные сборки и stdin/EOF, коды ошибок, локальные зависимости, консоль, ограничение вывода и Stop при заполненном stdin. Интеграционные проверки требуют Bash / Go на машине сборки; при их отсутствии они пропускаются.

## Архитектура

```
client.wexmanager
├── WexApp, AppContainer        — Application и ручной DI (только applicationContext)
├── core/
│   ├── fs/        FileItem, Location (локально/архив), LocalFileSystem (lstat), сортировка и фильтр
│   ├── ops/       TaskManager (копирование/удаление/архивы/подпись), TrashManager, FileOperationService
│   ├── archive/   ArchiveEngine (commons-compress): индекс, распаковка, сжатие, изменение ZIP; Unrar (RAR5)
│   ├── apk/       анализ APK, AXML и ARSC, подпись (apksig) и ключи в Keystore, установка split-APK
│   ├── dex/       DexSession (clazzpatcher), .class ⇄ csmali, декомпиляция в Java (jadx)
│   ├── db/        SQLite
│   ├── network/   SFTP/FTP/SMB/WebDAV
│   ├── settings/  AppSettings/UserData в DataStore (JSON)
│   ├── icons/     иконпаки и их каталог, миниатюры для Coil (APK, обложки, PDF, шрифты)
│   └── util/      форматирование (ru-RU), FileOpener, хеши, входящие интенты, ярлыки лаунчера
├── feature/       browser, editor, viewer (изображения, медиа, HEX, PDF, шрифты), apk, search, analyzer,
│                  tools (корзина, задачи, очистка, справочник Smali), terminal, network, compare, settings, onboarding
└── ui/            тема (Expressive), навигация (Navigation 3), общие компоненты
```

- UI — Jetpack Compose, Material 3 `1.5.0-alpha` (Expressive API: MotionScheme.expressive, FloatingToolbar, LoadingIndicator, wavy-индикаторы, SegmentedListItem, MaterialShapes и морфинг форм).
- Состояние — ViewModel + StateFlow; навигация — Navigation 3 с ViewModel-скоупом на запись.
- Тяжёлая работа — на `Dispatchers.IO` с отменой; LeakCanary в debug-сборке.

## Сборка

```bash
./gradlew :app:assembleDebug        # отладочная сборка
./gradlew :app:assembleRelease      # release с R8 (подпись настройте сами)
./gradlew :app:assembleBenchmark    # release + отладочная подпись, applicationId *.bench — для замеров
./gradlew :app:testDebugUnitTest    # unit-тесты (ядро, архивы, хеши, инструменты текста)
```

Требования: JDK 21, Android SDK 37, minSdk 28.

Модуль `:clazzpatcher` — DEX/smali и JVM class/csmali (собственная библиотека автора, Kotlin/JVM).

ripgrep лежит в `app/src/main/jniLibs/<abi>/librg.so` (arm64-v8a, x86_64) — исполняемый файл, который установщик распаковывает в
`nativeLibraryDir`. Пересобрать: `tools/build-ripgrep.sh` (нужны rustup с целями `aarch64-linux-android`, `x86_64-linux-android` и NDK r28+;
по умолчанию тулчейн берётся из `~/.local/share/wex-rust`). ripgrep — MIT/Unlicense, © Andrew Gallant.

UnRAR — `app/src/main/jniLibs/<abi>/libunrar.so`, собирается `tools/build-unrar.sh` (NDK r28+, исходники RARLAB с проверкой SHA-256).
